# 横浜市 財政ダッシュボード（2011〜2024年度決算）

横浜市の財政データ（普通会計決算ベース）を可視化した公開ダッシュボードです。

- **公開ページ**: https://yukinobu-nakamura.github.io/yokohama-zaisei-dashboard/
- 内容: 主要指標の推移／歳入の構成／歳出（性質別）／基金・市債残高／会計区分（当初予算）／大都市比較／将来推計・健全化指標
- 単体HTML・オフライン動作（外部通信なし）・スマホ対応

## 出典

- 総務省「決算カード」「財政状況類似団体比較カード」 https://www.soumu.go.jp/iken/zaisei/card.html
- 横浜市財政局「決算カード」「普通会計決算の概要」「IR資料」「予算案資料編」「財政ビジョン」「長期財政推計」ほか（city.yokohama.lg.jp）
- 政府標準利用規約・PDL1.0（公共データ利用規約）に基づき出典明記のうえ利用
- データ確認日: 2026-10-05
