# 横浜市 財政ダッシュボード（2010〜2024年度決算・15年）

横浜市の財政データ（普通会計決算ベース・15年完全系列）を可視化した公開ダッシュボードです。

- **公開ページ**: https://yukinobu-nakamura.github.io/yokohama-zaisei-dashboard/
- 内容: 主要指標の推移／歳入の構成（8分類・残差ゼロ）／歳出（性質別8分類）／基金・市債残高／会計区分（当初予算）／大都市比較／将来推計・健全化指標
- 期間スライダーで表示年度を絞り込み可能
- 単体HTML・オフライン動作（外部通信なし）・スマホ対応

## データと検証

- 総務省「市町村別決算カード」神奈川県版の横浜市分15年（平成22〜令和6年度）を機械抽出
- 恒等式検証: 歳入款Σ＝歳入合計・性質別Σ＝歳出合計・義務的経費＝人件費+扶助費+公債費・実質収支＝歳入歳出差引−繰越財源（全15年で残差ゼロ）
- 隣接年の連続性照合（各年度カードの前年度値と前年カードの当年度値の突合）を実施（差異3件・いずれも0.05億円未満で表示精度に影響なし）

## 出典

- 総務省「市町村別決算カード」 https://www.soumu.go.jp/iken/zaisei/card.html を加工して作成（政府標準利用規約〔第2.0版〕・公共データ利用規約〔PDL1.0〕に基づく利用）
- 横浜市財政局「決算カード」「普通会計決算の概要」「IR資料」「予算案資料編」「財政ビジョン」「長期財政推計」ほか（city.yokohama.lg.jp）の数値データを利用（数値データ・簡単な表・グラフ等は著作権の保護対象外である旨を市サイトが明記）
- データ確認日: 2026-10-05

## 注意

- 金額は億円に統一（原典は千円単位）。表示は四捨五入のため合計に±1億円程度の表示差が出る場合があります。
- 「要再確認」「未確認」と付した数値は一次資料での再確認前の参考値です。
- 基金は決算カード（普通会計）ベース。横浜市IR資料の「基金残高」（全会計・全基金）とは定義が異なります。
- 本ページは公開データの可視化であり、特定の候補者・政党への投票を呼びかけるものではありません。
